# Foodmine Selenium Automation Testing

This project contains Selenium automation testing for the Foodmine website using Java and Eclipse IDE.

## Implemented Tests

* Login Test
* Register Test
* Search Test
* Homepage Test
* Food Details Test
* Cart Test

## Technologies Used

* Java
* Selenium WebDriver
* JUnit 5
* Eclipse IDE
* Maven

## Project Description

The automated tests were created to validate the main functionalities of the Foodmine web application.

The tests include validations and assertions and can run automatically without manual intervention.

## Test Coverage

The project covers:

* Valid and invalid login
* Valid and invalid registration
* Food searching
* Homepage loading
* Opening food details
* Adding and removing items from cart

## Execution

To run the tests:

1. Open the project in Eclipse IDE
2. Ensure the Foodmine application is running on:
   http://localhost:3000
3. Right click on any test class
4. Select:
   Run As → JUnit Test
